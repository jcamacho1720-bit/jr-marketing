# JR Marketing — Dale play a tus ideas

Sitio web dinámico y moderno para **JR Marketing**. Este proyecto contiene un diseño interactivo, animaciones de scroll adaptativas (Scroll Storytelling), mapa SVG de cobertura y un estilo visual prémium con colores vibrantes y tipografía Montserrat.

## 🚀 Tecnologías utilizadas
*   **HTML5**
*   **CSS3** (Variables CSS, Animaciones nativas, Flexbox/Grid)
*   **Vanilla JavaScript** (Intersection Observer y lógica de scroll personalizada)

## 📁 Estructura del Proyecto
*   `jr-marketing-prototipo (2).html`: Prototipo interactivo principal.
